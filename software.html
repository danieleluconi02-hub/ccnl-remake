Deep Belief Network Code

Unsupervised deep learning for cognitive modeling

Code for training Deep Belief Networks (DBNs) on cognitive modeling tasks. Developed as part of the ERC GENMOD project, these implementations enable large-scale simulations on GPUs and clusters. Includes the novel iterative DBN (iDBN) algorithm for joint-layer learning.

All implementations are available on the lab's GitHub alongside MATLAB routines for analyzing trained networks (receptive field visualization, weight distributions, reconstruction quality).

La Gara dei Numeri

Italian Number Race — dyscalculia intervention game

An Italian adaptation of "The Number Race" (Wilson, Dehaene, Pinel, Revkin, Cohen & Cohen, 2006). A free educational video game designed to strengthen numerical abilities and treat developmental dyscalculia in children aged 4–8.

The game uses an adaptive difficulty algorithm that monitors the child's performance and adjusts task difficulty in real time — reducing response time, switching to symbolic quantities, and introducing arithmetic operations at advanced levels.

Released under the GNU General Public License (prohibiting commercial sale). Includes an Italian user manual. Can also be used for children without specific learning disorders.

Play in Playground

Target audience

Children ages 4–8. Suitable for dyscalculia intervention or number sense strengthening in typical development.

Environments

Jungle or ocean environments. Adaptive difficulty based on child performance history.

Evidence base

Based on Wilson et al. (2006). Game structure grounded in current neuroscience of numerical cognition.

Languages

Italian (this version). English version ("The Number Race") available from original authors.
